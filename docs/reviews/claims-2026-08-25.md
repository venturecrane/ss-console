## Three findings were understated at 2026-08-23

- **F7** was recorded as one duplicated class. It is **38 duplicated symbols**
  across 14 `pre_run.py` files — an entire heartbeat library. The duplication
  is forced: the scheduler stages `pre_run.py` alone, so these files cannot
  import a shared module. The defect is silent divergence, so the gate is a
  sync contract over 23 symbols, not a deduplication demand.
- **F12** was recorded as "no workflow runs them". `@vitest/coverage-v8` was
  never a dependency, so the script had never run at all; with the provider
  installed it reports **0/0 files**. Four numbers described a floor nothing
  measured, for four months.
- **F9** was recorded as "28 `sys.path.insert`". 22 are ordinary entrypoint
  behaviour in `operator/bin/*.py`. Only **6** are library modules, and only
  those are a smell.
