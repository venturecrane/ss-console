# Which review findings are facts, and which are opinions

Every claim below is one of two kinds:

- **FACT** — there is a command. Run it, get the same answer, any day, any agent, no
  judgment involved. If the command's output changes, the claim changed. That is the
  whole test.
- **OPINION** — a judgment about severity, design, or priority. Legitimate, sometimes
  important, but it will vary between agents and it is not evidence.

The two have been mixed together in every review this repo has produced, in the same
numbered lists with the same `[SEVERITY]` tags. That is the source of the
whack-a-mole: an opinion that changes between turns looks identical to a fact that
regressed.

**How to use this file:** run `bash docs/reviews/claims-2026-08-24.probe.sh`. **14 of the
16 facts re-derive themselves.** F14 (branch protection) has no check in the probe, and
F16 (production row count) is skipped unless you pass `--remote`. Both are marked below.

An earlier draft of this line claimed "every FACT re-derives itself", which was false —
caught by the critic reviewing the plan this file seeded, not by the author. It is
corrected rather than quietly fixed, because a document arguing that claims need
commands should not carry an unchecked claim about itself.

Recorded because a reliability document that omits its author's own errors is not one.

| Claim | Reality | Root cause |

| "Run `knip --production` to surface the ~50 dead exports" | Reports **1**, not ~50. | Published a remedy I never executed. |
| "`__all__` has 37 entries" | **36** (`ast.literal_eval`). | Eyeballed a list instead of counting it. |
| "Security: zero exploitable findings" (graded B) | Two HIGHs existed, in a report I never received. | Graded my own incomplete sweep without knowing it was incomplete. |
| "A CRITICAL and six HIGHs nobody has acted on" | One of the six was partially fixed by my own PR. | Sloppy recount. |
| "29 `sys.path.insert` calls" (from an agent) | **28.** | Accepted an agent's number without re-running it. |

Every one of these is the same failure: **a claim stated with more confidence than its
evidence supported.** Five of six would have been caught by the rule this document
exists to establish — no claim without a command.
