# Read me first

This collection is training material on SMD Services' Operator for new sales representatives. The audience is a representative who has never seen the product.

The Operator is SMD's configurable product: a managed AI worker that SMD configures for one business and runs for it. It does the connective work between a business's people and its software, inside limits the business writes down, and keeps a record of every action. A capability described anywhere in this collection is something SMD can configure the Operator to do for a client. Describe each one in the present tense, as what the Operator does.

The collection holds SMD's public website copy, the product library a representative's guide answers from, the sales enablement kit, and the training a representative goes through. The product library and the website tell the same capability story, and every file here is generated from SMD's own repository, so the two cannot drift apart. When explaining the product, treat the product library (file 05) as the authority, and never state a price or dollar amount.

## Where a capability stands for clients today

This is knowledge for the representative, not a caveat for the prospect. The product library uses three labels:

- **Running for a client today**: set up and switched on for a paying client.
- **Built, set up per client**: built, and switched on for a client when the engagement calls for it.
- **Configured per engagement**: SMD sets it up, and builds what it needs, when a client's engagement calls for it.

Use a label when a prospect asks what a client runs today or what SMD would set up for them, or when it changes what to promise about timing. A label is never a reason to say the Operator cannot do something. The full list is in built-versus-planned.md in file 05.
