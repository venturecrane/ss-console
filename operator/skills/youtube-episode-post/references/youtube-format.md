# YouTube title and description format

## Title

- Under 70 characters (YouTube allows 100; search results cut near 70).
- The episode's subject in plain words, then the show's name if the firm uses
  one: "Winter driving in the valley | <show name>". A pipe is fine; an em dash
  is not.
- No claim about the firm, no exclamation mark, no ALL-CAPS words, no emoji.

## Description

- 120 to 250 words. The first two lines are what YouTube shows before "more",
  so they say what the episode covers.
- Then three to five plain lines on what is discussed, in the order the
  episode takes it. Timestamps only if the episode's own description gives
  them.
- Then the firm line: "<Firm name> is a personal injury firm in <office
  city>." and the firm's website from `firm.site_urls`.
- Then one general line: "This episode is general information, not legal
  advice." Use the firm's own blog disclaimer instead when the tone guide asks
  for it.
- No hashtags beyond three, no links other than the firm's own site.
