# Connecting to the Guide

This document explains how a representative starts using the guide with an invite code.

## How to connect

1. Get an invite code from SMD Services. Codes come only from SMD Services. A code starts with SMD followed by three groups of four letters and numbers, separated by hyphens.
2. From your own email address, the one you will use with the guide, send the guide an email with the code in the subject or the body. Nothing else is needed in that first email.
3. You get a short welcome reply in the same thread. From then on, email the guide from that address and ask your questions as usual.

Things to know:

- One code is for one person, unless SMD Services says otherwise when it gives you the code.
- Codes expire. An expired code, a code already used, or a mistyped code gets no reply, and nothing changes.
- If no welcome arrives, do not keep retrying: repeated attempts are paused for a while. Ask SMD Services at team@smd.services.
- If SMD Services already listed your address, you need no code. Just email your question.
- Connecting with a code works by email only. Access by chat is set up by SMD Services.
- Keep your code to yourself until you use it, and never forward it to anyone else.
- To disconnect an address, ask SMD Services at team@smd.services.
